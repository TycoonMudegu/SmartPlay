SIMPLE FAMILY STREAMING

One film.
One Play option.

Configure a television once. Smart Play compares available stream listings, checks their estimated bandwidth needs and returns one recommended choice to Stremio.

No account, database or AI key needed. Your settings are encoded in the installation link. The add-on still needs to be hosted and Stremio may require you to select the single recommended stream.

1. Choose the viewing setup

Choose a starting profile, then adjust settings for each TV.

Use 0 for no fixed size limit. Smart Play will still reject files whose estimated average bitrate exceeds your connection budget.

2. Stream sources

Enter the manifest URLs of your stream-provider add-ons, one per line. The host must be approved by the server administrator.

Checking approved hosts…

Use only sources you are authorised to access. Do not include API keys or private credentials: your configuration is inside a shareable URL.

3. Install in Stremio

Generate your link, then install it in Stremio's Add-ons section.

If the app does not open automatically, paste the copied URL into Stremio's add-on installation field.

Changing settings creates a new URL. Remove the old Smart Play installation before installing the replacement.

Edit an existing profile

Paste an earlier Smart Play manifest URL to recover its settings. Nothing is stored in a database.

Test live results

Test a title against the configured sources. This only checks reported metadata, not actual playback.

Stream ranking preview

Upload Torrentio JSON for an offline comparison. No external stream fetch is needed.
